Got it 👍 — saving your Conda environment is super useful so you can:
Reinstall it later if something breaks
Share it with classmates / your professor
Keep track of exactly what versions you used
🔹 Save your environment to a YAML file
After you’ve activated your environment (conda activate myenv), run:
conda env export > environment.yml
This creates a file called environment.yml in your current folder.
It will contain all packages and versions installed in myenv.
🔹 Recreate the environment later
On the same computer (or another computer with Conda installed):
conda env create -f environment.yml
This will build a new environment with the exact same setup.
🔹 Update an environment from a YAML file
If you add packages and want to update the file:
conda env export > environment.yml

And to update an existing environment from it:
conda env update -f environment.yml --prune

⚡ Pro tip: If you’re working on projects, keep the environment.yml file inside the project folder. That way, anyone who clones/opens your project can just run conda env create -f environment.yml and be ready to go.
